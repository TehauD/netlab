This reads Connections.csv from LinkedIn's official data export and analyzes it as a bipartite affiliation network — people linked to employers, stamped with an acquisition date. Parsing runs locally; the analysis engine runs on localhost if you started it, otherwise entirely in this tab.

Where to get the file:
LinkedIn → Me → Settings & Privacy → Data privacy → Get a copy of your data → select Connections → Request archive.
Delivery takes 10 minutes to 24 hours.

This covers your own first-degree connections only. LinkedIn does not expose anyone else's network through the export or any public API, so second-degree structure genuinely is not in this file — and this tool does not invent it. See the Method tab for what is observed versus inferred.
